# Digital Nepal Heritage

A responsive, multi-section introduction to Nepal's destinations and cultural heritage. Built as a Web Development class assignment using HTML, CSS, and JavaScript.

## Project files

- `index.html` — semantic page structure and content
- `styles.css` — visual design, CSS Grid/Flexbox, and responsive media queries
- `script.js` — mobile navigation and click interaction
- `images/` — local photos of the Himalayas, Pokhara, the Kathmandu Valley and Newari wood carving

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. An internet connection is needed for Google Fonts and the remote Unsplash photographs.

## Assignment requirements covered

- Header, navigation, main content, content cards, and footer
- Three destination cards and three culture sections
- CSS typography, colors, spacing, borders, Grid, and Flexbox
- Responsive layout with media queries at 760px and 390px
- JavaScript DOM selection and event listeners
- Separate HTML, CSS, and JavaScript files

## Publish with GitHub

1. Sign in at https://github.com/
2. Create a new public repository named `digital-nepal-heritage`.
3. Upload the files and folders from this project (not just the ZIP file).
4. Add a commit message such as `Complete Digital Nepal Heritage website`.
5. Open the repository and copy its URL for submission.

Optional: To publish a live website, open the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will show the published website URL after deployment.

## Note

This is a student project concept. Destination descriptions are introductory, and external tourism links are provided for further information.
